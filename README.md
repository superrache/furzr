**furzr** (2013) explores the world of music by browsing similarity maps between artists and listening to samples.

The app lives in `web/` (furzr 2: Vite + TypeScript + force-graph, static site, no backend):

```
cd web
npm install
npm run dev      # development server
npm test         # unit tests
npm run build    # static site in web/dist
```

Three modes: **similar** artists, **influences** (who inspired an artist, and whom they inspired) and **movies**.
Two ways to grow the map: **Snake** (Crazy Snake, unexplored names vanish at each step) or **Tree** (Huge Tree of Death, nothing is removed).

Data: [Last.fm API](https://www.last.fm/api) (similar artists, bios), [Deezer API](https://developers.deezer.com/api)
(audio previews, pictures, autocomplete), [Wikidata](https://www.wikidata.org) (influences) and
[TMDB](https://www.themoviedb.org) (movies). This product uses the TMDB API but is not endorsed or certified by TMDB.

The interface is available in 12 languages (those for which Last.fm provides artist bios), detected from the browser
and switchable from the language menu.

Keys go in `web/.env`: `VITE_LASTFM_API_KEY` (required) and `VITE_TMDB_API_KEY` (optional, enables the movies mode).

The legacy 2013-2015 version (jQuery/arbor.js front, Google App Engine Java backend) has been removed; it is still available in the git history.

## URL parameters

`?artist=<name>&lang=<en|fr|de|es|it|pt|pl|ru|sv|tr|ja|zh>&mode=<influences|movies>&growth=<snake|tree>&similar_number=<1-50, default 16>&sound=off`

Maps are shared through the URL fragment: `#map=<compressed map>` (generated by "Share this map").
